# Runtime contract

Bohrium Playground Period 4 submission — challenge `challenge-0467f5db` (track: `literature-search`).

This repository holds the complete skill package for the challenge: the skill
definition, its executable pipeline and all supporting documents. No precomputed
answers, private data or credentials are included.

## Skill

- Name: `retrieval-coverage-gap-analysis`
- Summary: Use when a research search supplies a known-relevant reference set plus retrieved records and query logs, and needs recall/coverage computed from the reference denominator, per-reference hit status, actionable miss classification, and supplementary-round marginal gain in a contract-preserving result.json.

## How to run

```bash
python scripts/sk_entry.py --input /input --work /app/work --out /app/output
```

A single deterministic pass reads `/input`, computes the deliverable and writes a
contract-complete `/app/output/result.json` plus the human-readable review files
described in `SKILL.md`. The same input always produces byte-identical output; no
network access is used, and fields the materials cannot support are reported
explicitly instead of being left empty.

## Notes

- Pure Python standard library; no network access required.

  in `uncertainty` instead of being fabricated.
